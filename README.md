# projetplanb-site

Site du projet **Projet Plan B** — *Refaire culture en Communs*.

Droit civil des Communs, mémoire des luttes paysannes-libres, libertaires et d'éducation populaire. Cartographier ce qui a fonctionné, nommer le dispositif juridique qui le rend reproductible, l'ancrer dans un précédent documenté.

## Stack

- Astro 6 + MDX + React + D3
- Node ≥ 22
- Déploiement : Netlify
- Domaine : `projetplanb.org`

## Dev local

```bash
npm install
npm run dev      # localhost:4321
npm run build    # output dist/
npm run preview
```
